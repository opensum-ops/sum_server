1 · Install the agent

Install sum-agent on the target host (release binary or wheel), then run the following as the user that will run the agent.

2 · Configure and enroll

export SUM_AGENT_SERVER_URL={{ server_url }}
sum-agent enroll --token {{ enrollment_token }}

3 · Run it

sum-agent run

Optional · systemd service

cat <<'EOF' | sudo tee /etc/systemd/system/sum-agent.service
[Unit]
Description=OpenSUM agent
Wants=network-online.target
After=network-online.target

[Service]
Type=simple
Environment=SUM_AGENT_SERVER_URL={{ server_url }}
ExecStart=/usr/local/bin/sum-agent run
Restart=on-failure

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable --now sum-agent

The ordering on network-online.target also matters at shutdown: it lets the agent send its goodbye report before the network goes away, so the host shows as rebooting/powered off instead of unreachable.
